# Encontre o erro no algoritmo

Jogo educativo para a Feira de Ciências 2026, do projeto **A evolução do algoritmo**, uma homenagem a Ada Lovelace.

Quem joga arrasta blocos de instruções para montar um algoritmo. O código JavaScript aparece ao vivo e a "máquina" executa cada passo, mostrando que o computador faz exatamente o que recebe, mesmo quando a ordem está errada.

- **Jogar:** https://lauraesa.github.io/encontre-o-erro/
- **Documento do projeto:** [Projeto - Encontre o erro no algoritmo.md](Projeto%20-%20Encontre%20o%20erro%20no%20algoritmo.md)

O jogo é um único arquivo (`index.html`), feito em HTML, CSS e JavaScript puro, e funciona offline.
